Set up your Google Sheet

Your data syncs to a private Google Sheet that only you control — nobody else can see it. Takes about 3 minutes, once.

Step 1

Create a new Google Sheet at sheets.google.com, then open Extensions → Apps Script.

Step 2

Delete the starter code, then paste in the backend script.

Step 3

Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone, then Deploy. Copy the URL it gives you.

Step 4

Paste that URL here:

You can always set this up later from Settings.
